# Сюда кладут музыку

Шесть файлов, имена ровно такие (расширение любое из
`.m4a .opus .webm .mp3 .ogg .wav`, предпочтительно `.m4a`):

```
title.m4a           титульный экран
dialogue_cold.m4a   Учёт, архив, читальня  (hall, counter, archive, ledger, audit)
dialogue_low.m4a    подвалы и низ          (vault, lowest, hourglass, tower)
dialogue_out.m4a    улица и дорога         (gate, road, garden, guild)
battle.m4a          любой бой
death.m4a           церемония смерти и Сход
```

Файл начинает играть сам, ничего подключать не нужно: слот собран так же,
как арт-слоты (`packages/client/src/lib/art.ts`). Пустой слот — законное
состояние, игра просто молчит.

Требования к файлам, зачем они такие и где брать — в `МУЗЫКА.md` в корне
репозитория. Коротко: моно, 48–64 кбит/с, петля 40–90 с, ≤400 КБ на файл,
≤1.5 МБ на все шесть.

Лицензии — в `ИСТОЧНИКИ.md` рядом, по строке на файл. Без него музыку не
принимают: вопрос «а можно ли это выкладывать» задают через полгода.

Проверка после добавления:

```
pnpm --filter @nameless/client build
node tools/soundcheck.mjs http://localhost:4173
```
