# STYLE — визуальный язык «Безымянного»

Контракт художника: палитра, шрифты, размеры, рамки, иконки, отступы,
анимация, тест гармонии. Значения синхронизированы с
`packages/client/src/theme.css` и `packages/content/assets/palette.css`.
Меняешь цвет здесь — правь оба файла и `procedural/procedural.ts#PALETTE`.

## 1. Палитра

Тон тёмный: потемневшее серебро, усталое золото, зола, пятна украденной
памяти. Тема одна, светлой альтернативы нет.

| Переменная | Hex | Назначение |
|---|---|---|
| `--bg-0` | `#0d0b0e` | Самый дальний фон — обшивка экрана |
| `--bg-1` | `#151219` | Средний слой — под панелями, за контентом сцены |
| `--bg-2` | `#1e1a22` | Ближний слой — верх градиентов, шапки экранов |
| `--surface` | `#241f29` | Карточки, панели, поднятые поверхности |
| `--line` | `#372f3d` | Разделители, обводки, тонкие рамки не по тиру |
| `--text` | `#e8e2ea` | Основной текст |
| `--text-dim` | `#9a90a0` | Приглушённый — подписи, флейвор |
| `--text-faint` | `#6b6470` | Бледный — метки, плейсхолдеры |
| `--accent` | `#c9a227` | Золото — главный интерактивный цвет: кнопки, активный выбор, лот |
| `--memory` | `#7fd3d0` | Закреплённая память — отголоски, тир 3 |
| `--lie` | `#b06fd0` | Посул / обман — ложные обещания, ось честности |
| `--danger` | `#c1483f` | Урон, угроза, необратимые решения |
| `--gold` | `#d8b34a` | Монеты, цена, лот на Прилавке — теплее `--accent` |
| `--hp-ally` | `#6fbf73` | Полоса здоровья союзника |
| `--hp-enemy` | `#b8574e` | Полоса здоровья врага |
| `--tier-1` | `#6b6470` | Рамка тира 1 — тусклый камень |
| `--tier-2` | `#a8935c` | Рамка тира 2 — тронута золотом |
| `--tier-3` | `#8fd6d1` | Рамка тира 3 — цвет памяти, светится |

Правила: `--text` на любом фоне — не ниже AA. Цветные роли (`--memory`,
`--lie`, `--danger`, `--accent`, `--gold`) не используются как текст на
цветном фоне того же тона — только акцент на тёмной подложке или
заливка/обводка мелких форм.

## 2. Шрифты

- **`--font-display`**: `"Playfair Display" 700, "PT Serif", Georgia, serif`
  — заголовки экранов, имена павших, титул, короткие акцентные строки.
  Только начертание 700; для абзацев не использовать.
- **`--font-text`**: `"PT Sans" 400/700, "Noto Sans", system-ui, sans-serif`
  — весь интерфейс, диалоги, описания. Полная кириллица (проект ru/en).
- Оба нарезаны на latin/cyrillic woff2 (`assets/fonts/`),
  `font-display: swap`.

### Шкала размеров: 12 / 14 / 16 / 18 / 22 / 28 (px)

| Размер | Роль |
|---|---|
| 12 | Метки, счётчики, служебные подписи |
| 14 | Вторичный текст, флейвор, подсказки выбора |
| 16 | Базовый текст интерфейса и диалога |
| 18 | Акцентный текст — вопрос выбора, HP-число |
| 22 | Заголовок карточки/панели, подзаголовок экрана |
| 28 | Заголовок экрана / титул |

Проект — портретный мобильный UI, `--tap: 48px`, ширина 360–430px.
Дробные размеры в `screens.css` (15.5, 16.5…) — ручная подгонка
интерлиньяжа, не ступени; новый текст округляй к ближайшей ступени шкалы.

## 3. Рамки карточек по тирам

Карта юнита — 300×400 (3:4). Рамка — поверх арта, середина прозрачна.
Источник формы — Kenney «Fantasy UI Borders» (CC0), перекраска скриптом
`packages/content/assets/ui/nameless/tint.py`; подключение —
`border-image` с 9-slice (`slice 16`) на псевдоэлементе `::after`
(`packages/client/src/screens.css`).

| Тир | Цвет | Исходник Kenney | Ширина | Орнамент |
|---|---|---|---|---|
| 1 | `--tier-1` | `panel-border-015` | 7px | голая рамка |
| 2 | `--tier-2` | `panel-border-001` | 9px | + квадрат в углах |
| 3 | `--tier-3` | `panel-border-002` | 11px | + угловой узел (двойная петля) |

Правила:
- Тир читается по «весу» рамки даже в градациях серого: монотонный рост
  7→9→11px и декора; декор никогда не убывает с тиром.
- Рамка живёт только на `::after` (`border` на элементе ломает пропорцию
  3:4 и подрезает арт), `pointer-events: none`.
- Процедурный арт (`unitCardSvg`) рисует свою рамку внутри SVG; под рамкой
  Kenney она прячется зумом `.card-art` `scale(1.16)` в обойме
  `overflow: hidden`. Перестанут вкладывать `frameSvg` — зум убрать.

### Рамка как знак: что её получает, а что нет

- **Рамка Kenney = объект, с которым действуют или который хранят**: карта
  юнита, кнопка выбора, способность, главная кнопка экрана, вкладки описи,
  карточка выкупленной памяти.
- **Скругление + линия 1px = текст, который читают**: реплики, нарратив,
  подсказка обучения, флейвор, вторичная кнопка (`.ghost-button`).

Тон рамки по громкости: `--text-faint` — обычная цель, `--accent-dim` —
активное/главное, `--tier-1/2/3` — карта юнита, `--memory` — выкупленная
память. Других цветов рамок не заводить (`--line` пробован — не читается
на `--surface`).

## 4. Иконки способностей

- viewBox строго `0 0 24 24`, физический размер 24×24.
- Только `stroke="currentColor"`, `fill="none"`; заливка — лишь мелкий
  акцент (капля, огонёк, зрачок).
- Одна толщина на весь набор: `stroke-width="1.5"`, `linecap/linejoin
  round`. Толщины не смешивать.
- Один силуэт — один смысловой объект, без лишней детализации.
- 24 базовых имени — `ICON_NAMES_LIST` (`procedural.ts`); расширять тем же
  стилем, параллельный набор не заводить.

### Знаки: кто говорит, чей юнит, что за место

Второй — и последний — иконочный слой. Иконка отвечает «что делает», знак —
«кто это»/«где это». Знак не ставится в кнопку, иконка — вместо портрета.

- **Источник — тот же автор**: знаки нарезаны из «700 RPG Icons» Lorc
  (OpenGameArt, CC BY 3.0); один почерк с набором `Icon.tsx`.
- **Форма знака — заливка**, форма иконки способности — штрих 1.5:
  разделение слоёв, знак читается пятном и на 27px, и на 300px.
- **Цвет знака = дом, глиф = человек.** Раскладка домов по цветам — как в
  §1 (золото — учёт, `--text-dim` — стража, `--danger` — Ревизия,
  `--memory` — память и отголоски, `--lie` — торговля чужим,
  `--text-faint` — безымянные, `--hp-ally` — свой отряд). Цвет по
  характеру персонажа не назначается никогда.
- **Один дом — одно лицо, один спутник — своё**: дома показываются одним
  знаком на всех своих юнитов, спутники получают личный предмет.
- **Цвет запекается в PNG**; все знаки одного назначения — одной
  спрайт-лентой (`assets/emblems/{speakers,units,places}.png`), генератор —
  `assets/ui/nameless/emblems.py` (там таблица «ключ → файл → тон →
  зачем»). Размер задаёт только CSS-переменная `--mark-s`; второго ассета
  под второй размер не заводить.
- **Водяной знак** — мягкий край (`mask-image: radial-gradient`),
  прозрачность 0.05–0.1; плотный знак с ровной границей читается наклейкой.
- **Арт-слот пользователя главнее знака**: файл в `assets/cards/<id>.webp`
  или `assets/portraits/<id>` отменяет знак.

## 5. Отступы и радиусы

- Радиусы: `--r-sm: 6px` (сегменты, тэги), `--r-md: 10px` (карточки,
  кнопки, панели — чаще всего), `--r-lg: 16px` (крупные листы, шторки,
  экран смерти).
- Внешние отступы экрана: 20–24px на титульных/модальных, 10–16px в
  плотных игровых (бой, диалог), всегда + `env(safe-area-inset-*)`.
- Внутренние отступы: `10–12px 14px` для тапаемых (цель `--tap: 48px`),
  `6–8px` для плотных строчных элементов.
- `gap`: 12–14px между смысловыми блоками, 6–8px внутри компонента.

## 6. Анимация карт

Источник правды — `packages/client/src/screens.css` (`@keyframes`).

| Эффект | Keyframes | Длительность | Easing |
|---|---|---|---|
| Рывок к цели (атакующий) | `lunge-up`/`lunge-down` | 320ms | `cubic-bezier(0.3, 0, 0.2, 1)` |
| Тряска при уроне | `shake` | 300ms | `ease-out`, ±5px→±3px по X + вспышка `filter` на первый кадр |
| Всплывающие цифры | `float-up` | ~600–700ms | `ease-out`, вверх на −34px и затухание |
| Рассыпание при смерти | `crumble` | 420ms | `ease-in`; opacity→0, 3deg, scale 0.86, `grayscale(1) blur(2px)` |
| Появление элементов | `rise` | 240–620ms | `ease-out`; `opacity 0→1` + `translateY(8px→0)` |
| Дыхание/пульс | `breathe` | 2000ms+ | `ease-in-out`, opacity 0.35↔0.85 |

Правила новой анимации:
1. Урон/удар — всегда быстрый (250–350ms): импульс, не пауза.
2. Смерть/исчезновение — единственная медленная категория (400–450ms) и
   единственная с `ease-in` («оседает», не «отскакивает»).
3. Появление UI — `ease-out`, 200–650ms по размеру блока.
4. `prefers-reduced-motion: reduce` уважается глобальным правилом в
   `theme.css` — новые keyframes не должны требовать доп. логики.
5. Цветовые сдвиги в анимации — только смысловые цвета палитры.

## 7. Тест гармонии

Как проверить, что новый экран/арт не «из другой игры»:

1. **Один источник цвета**: каждый hex — переменная палитры или `shade()`
   от неё. Посторонний hex — ошибка.
2. **Один источник формы иконок**: `stroke-width="1.5"` в `viewBox 24×24`.
   Единственное описанное исключение — знаки (§4): заливка, другой слой.
   Третьего иконочного языка быть не должно.
3. **Один источник шрифта**: ровно два семейства — `--font-display` для
   1–2 коротких строк, `--font-text` для всего остального.
4. **Монохромная проверка**: скриншот в `grayscale(100%)` — иерархия
   должна остаться читаемой на одной светлоте.
5. **Тир на глаз**: три карты рядом — рамки различимы весом и декором даже
   без цвета.
6. **Детерминизм**: процедурный ассет по одному id генерится побайтово
   одинаково (`portraitSvg(id) === portraitSvg(id)`); `Date.now()` /
   `Math.random()` — баг.
