## Служебное

- Формат и данные проверены скриптом: каждый `id` из `speakers.json` и всех
  `units/*.json` встречается в этом файле хотя бы один раз (grep).
- Полные секреты, реплики по осям и сценарные примечания — только в
  `docs/CHARACTERS.md`. Этот файл — указатель «кто есть кто», не замена
  досье при спойлерных сценах.
- Четыре id без досье в `CHARACTERS.md` на момент написания: `svodchik`,
  `naryad_revizii`, `marya`, `starosta` — при первом использовании в сценах
  свериться с `CANON.md` (раздел 8, реестр NPC) и дописать досье в
  `CHARACTERS.md`.
