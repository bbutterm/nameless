# CODEX — Помянник

> Устройство и правила справочника. Кто читает: сценаристы строк (данные
> `packages/content/data/codex/`) и программист экрана. Правила языка канона
> действуют и здесь.

**Что это.** Герой каждый раз пуст, игрок — нет; Помянник — страница того,
что игрок помнит вместо героя. Книга имён, которую ведут, чтобы помнить:
практика человеческая, не ведомственная. Главный закон даром от имени:
**из помянника не вычёркивают** — ни строки, ни имени, никогда, включая
строки, оказавшиеся ложью (§5).

**Чья книга.** Не героя (он её не читает и не упоминает) и не персонажей
(в мире о ней не знает никто, реплик о ней не бывает — четвёртая стена).
Помянник ведёт **рассказчик** — голос без лица; читает — игрок. Термин:
Помянник (en: The Remembrance Book), id — `codex`.

---

## 1. Запись: из чего состоит

Одна страница на человека, пять полей сверху вниз:

1. **Имя** — как назвался при первой встрече, с подписью-должностью
   (`speakers.json` + blurb). Выяснилось, что имя чужое, — старое не
   правится, рядом ложится строка об этом (§5).
2. **Портрет крупно** — 120px+. Единственное место игры, где игрок
   рассматривает лицо: в ленте диалога портрет 44px, вторая группа черт
   видна только здесь.
3. **Приметы** — одна-две фразы: что с лицом сделала работа. Читают
   биографию с лица, не сюжет с экрана.
4. **Строки** — растущая часть, 2–5 на запись (§2). Короткий абзац от руки
   рассказчика с пометкой источника: *увидено* / *со слов* / *после твоей
   смерти* / *последняя*.
5. **Линейки** — пустые графлёные линии по одной на каждую ненайденную
   строку. Честный маркер неполноты, без «???» и намёков.

**Чем запись отличается от сцен — три проверяемых пункта:**

- **Взгляд со стороны.** Сцена — из глаз героя; строка — из глаз свидетеля,
  видевшего и то, чего герой видеть не мог. Правило приёмки: **каждая
  строка обязана нести минимум одну деталь, которой нет ни в одном узле
  сцен**. Строка-пересказ отклоняется без обсуждения.
- **Строки из несовместимых веток лежат рядом.** Запись копит все забеги;
  Помянник — единственное место, где «пощадил» и «добил» стоят на одной
  странице.
- **Крупный портрет** — поле 2.

Объёмы (экран 390×844): приметы ≤ 160 знаков, строка ≤ 220, запись целиком
≤ 1200 — один экран с коротким скроллом.

## 2. Как запись растёт

Три ступени (пять на телефоне неразличимы, две не дают роста):

- **1 «Вписан»** — первая встреча (автоматически движком): имя, подпись,
  портрет, приметы, одна стартовая строка.
- **2 «Строки»** — 2–5 строк на запись: главным — по 5, служебным — 2–3.
  Каждая привязана к прожитому узлу или событию (§6). Двигатель повторных
  прохождений: **у записи с 4–5 строками минимум одна лежит на ветке,
  несовместимой с другой её строкой** — дописать за один забег невозможно
  по построению.
- **3 «Последняя строка»** — одна, с отступом; открывается смертью
  персонажа, завершением его линии или финалом главы, после которой он не
  появляется. После неё линейки исчезают.

Не ступень, но сильный **тип строки** — «после твоей смерти»: что человек
сделал с твоей трухой и вещами, пока ты собирался в чулане. Герой этого не
видел никогда. Шесть-восемь таких на реестр, у ключевых людей.

Отвергнуты навсегда: рост от числа встреч (гринд без истории) и от числа
завершённых забегов (лотерея, не связанная с человеком).

---

## 3. Граница: что переживает забег

**Переживает смерть героя, финал забега и «Новую игру»:**
- открытые записи и строки (все ступени);
- тексты выкупленных воспоминаний прошлых жизней — навсегда;
- счётчик завершённых забегов.

**Не переживает (живёт в сейве забега):**
- отряд, гроши, флаги, осколки, оси — оси в Помянник не попадают ни в каком
  виде, «прогресса осей между забегами» не существует;
- закреплённые воспоминания как механика (юниты-отголоски, бонусы) —
  выкупаются каждый забег заново; Помянник хранит **тексты**, не эффекты;
- ожидающие строки (`codexPending`) — гибнут с брошенным забегом.

**Цена Помянника.** Не гроши и не лоты — **мёртвое время**: найденные
строки ложатся в книгу только на церемонии смерти и на финале забега, не
посреди вылазки. Пока ты жив, ты в сцене; книга дописывается, когда тебя
нет. Чтобы прочесть новое — надо умереть. Перечитывание открытого —
бесплатно всегда.

## 4. Помянник и церемония смерти

Два такта в церемонии:

1. **Такт воспоминания:** текст воспоминания, закрытого церемонией, ложится
   строкой в раздел «Ты» — навсегда, поверх любых будущих забегов.
2. **Такт строк:** «В Помянник дописано: N», список открытых за забег строк;
   тап по имени — в запись, возврат — назад в церемонию.

Ядро конструкции — асимметрия: **с каждым забегом герой всё пустее, а книга
игрока всё полнее; разница между ними — это и есть игрок**.

Обязательство для сценаристов финала: со второго прохождения финал — не
детектив. Игрок приходит зная всё; сцены финала обязаны выдерживать чтение
знающим (драматическая ирония: герой не знает, игрок знает). Проверка —
перечитать финал после полного Помянника: держится только на «вот это
поворот» — написан неверно. Мерило успеха: игрок на пятом забеге открывает
Помянник перед финалом перечитать, а не пролистывает.

## 5. Правила письма строк

- **Рука рассказчика.** Безлично-свидетельский тон, прошедшее время,
  третье лицо — кроме строк «после твоей смерти» (там «ты», как в текстах
  смертей). На странице не появляется голос, которого нет в игре.
- **Запреты языка** — канонные целиком, плюс два местных: никаких оценок
  («жестокий», «добрый» — оценивает игрок, не книга) и никаких обещаний
  вперёд (тизеры «но это было ещё не всё» запрещены).
- **Правило одной новой детали** (§1) — проверяется на приёмке построчно.
  Это самый дорогой текст игры на знак; строки-пересказы превращают книгу
  в чек-лист «собери всех» — лучше меньше строк.
- **Врать можно людям, книге — нельзя.** Пометка *со слов* записывает
  сказанное как сказанное, не ручаясь. Ложь вскрылась — рядом ложится
  строка с увиденным, старая **остаётся как была**: две противоречащие
  строки — не баг, а портрет лжеца его же словами. Механики «исправления»
  не строить.
- **Последняя строка** — самая короткая, без некролога и морали: одна
  деталь, по которой человека будут помнить. Потолок пафоса: «Труху смёл
  в угол, но выбрасывать не стал».

## 6. Данные и хранилище (реализовано)

Контент — `packages/content/data/codex/`:

```
CodexEntry { id (= speakerId|lifeId), kind: 'person'|'life',
             name, blurb, signs (≤160), lines: CodexLine[] }
CodexLine  { id ('osoka_l2'), text (≤220),
             source: 'seen'|'heard'|'after_death'|'last',
             unlock: meet(speaker) | node(scene,node) | memory(memory)
                   | char_death(char) | chapter_end(chapter)
                   | player_death_with(speaker) }
```

Выполненный unlock кладёт `line.id` в `state.codexPending`; перенос в
хранилище Помянника — только на церемонии смерти и финале забега, никаких
записей из сцен напрямую. Хранилище — отдельный ключ `nameless:codex:v1`
вне сейв-конверта: `clearSave()` и «Новая игра» его не трогают; стирание —
только явной кнопкой в настройках с формулировкой, отличной от сброса
забега. Property-тесты: строка из codex-storage не исчезает ни при каких
операциях; `codexPending` не теряет id при сейв/лоад; строка не
дописывается дважды.

Экран: список → запись, два уровня вложенности (исключение — переход из
церемонии с возвратом). Вход — с титула («всё стёрлось — это осталось») и
из паузы. Точка `--accent` у имени — «есть новое», гаснет открытием;
чисел-бейджей не вешать. Невстреченные не показываются вовсе; счётчик в
шапке — «вписано: 7», без знаменателя. **Опись — про этот забег, Помянник
— про все забеги.**
