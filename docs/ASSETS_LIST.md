# ASSETS_LIST — реестр графических ассетов

Все пути — относительно `packages/content/assets/`.

## Как это работает

Базовый слой графики — **процедурный** (`procedural/procedural.ts`): чистые
детерминированные функции, генерирующие SVG из id/seed, без сети и без
зависимостей. Реальные файлы — улучшение поверх: если файл лежит в нужной
папке под ожидаемым именем, клиент подхватывает его вместо процедурной
заглушки (см. `cards/README.md` для портретов юнитов).

## Что лежит в репозитории

| Файл | Что это | Источник |
|---|---|---|
| `fonts/playfair-700-{lat,cyr}.woff2` | Playfair Display 700 | Google Fonts, OFL |
| `fonts/ptsans-{400,700}-{lat,cyr}.woff2` | PT Sans 400/700 | Google Fonts, OFL |
| `procedural/procedural.ts` | Генератор портретов/арта карт/иконок/рамок/фонов | свой код |
| `procedural/samples/**/*.svg` | Примеры вывода генератора | сгенерировано локально |
| `palette.css` | Единая палитра + `@font-face`, согласована с `client/src/theme.css` | своё |
| `ui/nameless/` | Перекраска рамок Kenney (`tint.py`) и генератор знаков (`emblems.py`) | Kenney CC0 / Lorc CC BY 3.0 |

Лимиты: **≤300 КБ на файл, ≤10 МБ на весь набор ассетов.**

## Папки-назначения

| Папка | Что туда кладут | Формат |
|---|---|---|
| `ui/` | Панели, кнопки, рамки окон | svg/png |
| `icons/` | Иконки способностей сверх 24 базовых из `procedural.ts` | svg, viewBox 24×24 |
| `frames/` | Рамки карточек (процедурный вариант — `procedural/samples/frames/`) | svg/png |
| `backgrounds/` | Фоны сцен диалога/боя | svg/png/webp |
| `cards/` | Портреты юнитов от владельца — см. `cards/README.md` | webp/png 3:4 |

## Скачивание внешних ассетов (важно для звука, Б8/Б9)

Исходящий HTTPS в рабочей среде идёт через политику-прокси, которая
**блокирует** hosts вне списка пакетных реестров кодом `403 policy denial`
(проверено на game-icons.net, kenney.nl, opengameart.org). Бинарные паки с
внешних сайтов из сессии не скачиваются — файлы кладёт владелец руками, а
агент даёт список «что, откуда, какая лицензия» (образец процесса и правил
лицензий — `МУЗЫКА.md`). Перед использованием любого стороннего пака
лицензию проверять на самой его странице; при сомнении — не тащить в repo:
процедурный слой покрывает все роли.
