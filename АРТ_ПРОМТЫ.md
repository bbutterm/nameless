# Промты для генерации арта «Безымянного»

Файл для ручной генерации. Всё, что ниже, ложится в игру **без правок кода**:
кладёте картинку в нужную папку под нужным именем — она молча вытесняет
процедурную заглушку. Ничего пересобирать не нужно, Vite подхватывает папку.

---

## 0. Куда класть

| Что | Папка | Имя файла | Пропорция |
|---|---|---|---|
| Карта юнита | `packages/content/assets/cards/` | `<id юнита>.webp` | **3:4** (768×1024) |
| Портрет говорящего | `packages/content/assets/portraits/` | `<id говорящего>.webp` | 1:1 (512×512) |
| Фон арены и сцены | `packages/content/assets/backgrounds/` | `<id боя>` / `<ключ места>`.webp | **9:19.5** (по телефону) |

Форматы: `webp`, `png`, `jpg`, `svg`. **webp предпочтительнее** — бюджет всей
графики 500 КБ, из них уже занято 128 КБ. На карту закладывайте ≤12 КБ, на фон
≤25 КБ.

Фоны ищутся от частного к общему: сначала по id боя (`battle_wall_crew`), потом
по ключу места (`vault`). Одной картинкой `vault.webp` закрываются **все**
подвалы разом — начните с ключей мест, это 12 картинок вместо 30.

## 1. Общий блок стиля — вставлять в КАЖДЫЙ промт

Это главное в файле. Без общего блока получится тридцать четыре картинки из
тридцати четырёх разных игр, и это будет хуже нынешних заглушек.

```
STYLE: grim 19th-century ledger world. Ink engraving and woodcut, hatching and
cross-hatching, no smooth digital gradients. Muted, desaturated, almost
monochrome: cold bone grey #cdc4bb on near-black #0d0b0e. ONE accent colour only,
named per subject. Flat, graphic, poster-like, strong silhouette readable at
thumbnail size. Weathered paper texture, faint ink bleed. Melancholy, tired,
bureaucratic dread. No heroism.
NEGATIVE: no smile, no glow, no neon, no lens flare, no bloom, no rim light,
no blood, no gore, no horns, no fangs, no glowing eyes, no armour plates,
no fantasy pauldrons, no anime, no chibi, no 3D render, no photorealism,
no watermark, no text, no logo, no signature, no bright saturated colours,
no cyberpunk, no steampunk goggles, no skulls as decoration.
```

**Акцентные цвета по домам** — в промте называть ровно один:

| Дом | Цвет | Как называть в промте |
|---|---|---|
| Великий Ломбард, Учёт | `#c9a227` | `single accent: tarnished gold #c9a227` |
| Стража | `#9a90a0` | `single accent: cold steel grey #9a90a0` |
| Ревизия | `#c1483f` | `single accent: dried blood red #c1483f` |
| Братство Чистой Головы | `#7fd3d0` | `single accent: pale verdigris #7fd3d0` |
| Цех Жадной Памяти | `#b06fd0` | `single accent: bruised violet #b06fd0` |
| Улица, безымянные | `#6b6470` | `single accent: dead lilac grey #6b6470` |

**Правило, которое нельзя нарушать:** акцент **не красит кожу и не красит всё
подряд**. Он живёт в одной-двух вещах — воротник, бирка, инструмент, повязка.
Пробовали красить лицо цветом дома — все выходят больными.

## 2. Карты юнитов (34 штуки)

**Композиция для всех карт одинаковая, это важнее содержания:**

```
COMPOSITION: single figure, waist-up, centred, facing viewer, 3:4 vertical.
Head in the upper third. Empty dark space at the bottom quarter — the game
prints the name and health bar there. Plain near-black background with faint
vignette, no scenery, no ground line, no props floating around the figure.
```

> `<COMPOSITION>` + `<описание из таблицы>` + `<акцент дома>` + `<STYLE>` + `<NEGATIVE>`

## 5. Как проверить, что легло

```
pnpm --filter @nameless/client build
pnpm --filter @nameless/client exec vite preview --port 4173
node tools/shot.mjs http://localhost:4173     # вёрстка на трёх разрешениях
node tools/playthrough.mjs http://localhost:4173
```

Если картинка не появилась — почти всегда имя файла не совпало с id. Список
живых id: карты — таблица выше, говорящие — `packages/content/data/speakers*`,
ключи мест — `PLACE_RULES` в `packages/client/src/lib/emblems.ts`.

**Проверяйте на телефоне, а не на мониторе.** Карта в бою — 250px по ширине,
портрет в ленте — 44px. Красивая на весь экран картинка на 44px превращается
в серое пятно, и это главная причина, по которой арт приходится переделывать.
