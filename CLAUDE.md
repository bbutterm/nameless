# Контент-фабрика видео — правила для Claude

Репозиторий делает научпоп-ролики (ориентир — Kurzgesagt) полностью кодом. Пайплайн постоянно улучшается: если что-то в движке мешает — чини движок, а не обходи в отдельном ролике.

## Канал (решение заказчика)
- **Канал англоязычный (иностранный).** Все новые ролики — на английском: озвучка, надписи в кадре, субтитры, заголовки. Английский **простой** (уровень B1–B2): короткие предложения, частые слова, без идиом и сложных оборотов; термины объясняй сразу простыми словами.
- **Ролики не должны быть однообразными.** У каждого ролика свои: сквозная нить и главный образ, облик ИИ/героя-объекта, палитра-акцент и мир (космос, город, океан, лаборатория, бумага…), структура сцен и приём перехода, хук и финальная шутка, музыкальный характер (тональность, темп, инструменты). Перед раскадровкой сверься с прошлыми роликами (`videos/*/storyboard.md`) и запиши в новой раскадровке, чем ролик отличается.
- Русские версии — только как исходники/архив. Переводы старых роликов делаются языковыми вариантами (`<ролик>:en`, см. «Языки»).

## Перед работой над роликом
- Загрузи скилл `vizavi-motion` (`.claude/skills/vizavi-motion/SKILL.md`): единая нить, раскадровка с 3–5 вариантами на сцену, живая камера, музыка+SFX, обязательная итерация после первой сборки, проверка финального MP4.
- Стиль канала: плоские формы без обводок, тень — плоскостью (`shaded()`, `ball()`), индиго-ночь + циан (машина) / маджента (угроза) / янтарь (человеческое), звёзды/туманности/пыль, зерно `grain()`. Герой «ты» — `dude()` в `videos/basilisk/video.js` (круглая голова, глаза-точки). Персонажей показывай лицом или в профиль/¾ (как `dude()`: глаза, эмоция). Крупных людей со спины не рисуй — фигура «сзади за компьютером» в «Василиске» вышла слабой; лучше вид сбоку от стола, экран и лицо в кадре. У каждого ролика своя сквозная нить и свой облик ИИ из мира темы: глаз (`aiCore` с глазом) — образ «Василиска», не повторять его по умолчанию («везде не надо одинаково»). Персонажи и логотипы чужих каналов не копировать, реальных людей не рисовать похожими — только подписи/абстрактные аватары.

## Общий код
- `engine/kit.js` — общая графика (PAL, `sky`, `dude`, `mini`, `eye`, `aiCore` (опция `clips`), `paperclip`, `label`, `kineticWord`, `badge`, `heart`, `gear`, `envelope`, `earth`) и `sceneTimeline(N, ids)` → `{Bd, S, lw}`. Новое общее — добавляй сюда; правки проверяй пиксельным сравнением кадров старых роликов (`preview.py` до/после).
- `engine/audio/instruments.py → section(...)` — аранжировщик аккордовых секций для `score.py`; степные инструменты для исторической серии: `bowed` (смычковый, как морин хуур), `throat_drone` (обертонный бурдон), `frame_drum` + `gallop_drums` (ритм 6/8), `hooves`, `neigh`, `twang`, `wind`, `bleat`, `clang`.
- **Карты и история (серия «Who Ruled the World»)**: `engine/data/world.js` (Natural Earth 1:50m, суша/озёра/реки; Каспий — водой, Арал — исторический; пересобрать: `engine/tools/make_world.py`). В kit.js: `geoView/geoProj/geoRings/geoFill/geoDensify`, `drawGlobe(ctx, view, t, {under, colors, shade})` — ортографический глобус; регионы в `under` автоматически обрезаются по суше. Камера глобуса — ключи `[lon, lat, R]`, R сплайнится в логарифме (см. `viewKeys` в `videos/mongols/video.js`). Сквозная нить серии: `crown()` (корона лидера века) и `centuryBar()` (лента века сверху), `horse()` с циклом галопа, `dude(..., {hat: {kind: 'mongol'|'helmet'|'cap'}})`.
- Цвета: `mix()` принимает и `#hex`, и `rgb(...)` (результат другого `mix`).
- Не объявляй в ролике `const` с именами из kit.js (STARS, PAL, DUST…) — расширяй `Object.assign(PAL, {...})`.

## Новый ролик: шаги
1. `videos/<slug>/script.json` — строки `{id, say, text, pause_before}`. `say` — текст для озвучки (теги eleven_v4 вида `[curious]`, `[pause]` допустимы), `text` — для субтитров, `|` режет субтитр на куски. Факты проверяй.
2. Озвучка через ElevenLabs MCP:
   - `creative_create_flow` → `creative_generate_speech` (model `eleven_v4`, голос из `creative_list_voices`; для мрачного научпопа — Fuad `dWNEQ4rqRY6thcusuDyq`), сначала `estimate_only`, затем генерация (4 дубля по умолчанию), опрос `creative_get_flow_run_status`.
   - Скачай дубли (URL живут 2 ч), выбери, сохрани как `voice/narration.mp3`.
   - `creative_add_flow_asset_node` (generation_id выбранного) → `creative_transcribe_audio` (`eleven_scribe_v1`, connect_from = node) → скачай `words_download_url` в `voice/words.json`.
   - Запиши в `script.json → voice` id голоса, дубль и ссылку на flow.
3. `python3 engine/align.py <slug>` → `timings.js`. Паузы между блоками добавляются полем `pause_before` (голос режется в самой тихой точке промежутка, перегенерация не нужна). Scribe бывает позже на ~0.8 с у длинных пауз (растягивает слово перед паузой на тишину), поэтому align по умолчанию притягивает границы слов к реальным паузам в звуке (`snap_to_silence`, печатает «snap: N/M silences»; выключить — `"timing": {"snap": false}`). Если не все паузы сопоставлены — смотри кадры на этих словах.
4. `storyboard.md`, затем `video.js`: сцены `s1..sN`, `Bd` — границы сцен по строкам, синхронизация со словами через `lw(lineId, 'слово', n)`.
   **Внимание:** поиск слова — по префиксу, первое совпадение в строке. Для повторяющихся слов («кто», «не», «если», «каждый») указывай номер `n`. Префикс ловит и другие слова: «и» → «идея», «Все» → «всё», «умнее» → «умнеет», «цели» → первое «цели». Хелпер сцены пиши как `const L = (id, n = 0) => lw('<line>', id, n);`.
5. `VIDEO.events()` — все звуковые события с привязкой к словам; `score.py` — музыка по секциям + обработчики событий. Баланс: речь на ~10–13 дБ громче музыки (`MASTER = {'mgain', 'sgain', 'duck'}`); `mix.py` сам печатает `balance: voice is N dB above music+sfx`. Голос нормализуется по RMS речи (−16.5 дБ), а не по пику, так что разные голоса стоят одинаково.
6. Итерации: `engine/preview.py <slug> t1 t2 …` → смотри `out/<slug>/preview/sheet.jpg`; правь; только потом полный `engine/render.py` (720p по умолчанию, ≈10 кадр/с на 4 ядрах) и `engine/finish.py`.
7. Субтитры: `finish.py` всегда пишет `<v>.srt`; `--burn` — ещё `<v>_subs.mp4` с вшитыми субтитрами (Montserrat ExtraBold на полупрозрачной плашке); переводы субтитров — `videos/<v>/subs.<lang>.txt` (строка на кусок субтитра) → `<v>.<lang>.srt`. `--light` — `<v>_light.mp4` для отправки в чат (30 fps, смягчённое зерно, два прохода, ~5 МБ/мин; из версии с субтитрами, если есть `--burn`). Заказчику в чат отправляй лёгкую версию, полные — в ветку `renders`.
8. Шортсы/рилс: `videos/<v>/shorts.json` (отрезок по естественным паузам, хук-заголовок, `cx`-ключи окна) → `python3 engine/shorts.py <v> --preview` (листы кадров) → `python3 engine/shorts.py <v>` → `out/<v>/shorts/<name>.mp4` (1080×1920, 30 fps: хук сверху, квадратное окно в сцену 1:1 без растяжения, крупные субтитры с подсветкой слова, концовка «Full video on YouTube» на замершем кадре; рядом `<name>_light.mp4` ~4–6 МБ для чата). Звук — из готового `<v>.mp4`, поэтому сначала `finish.py`.
9. Превью (обложки): `videos/<v>/thumbs.json` → `python3 engine/still.py <v> --thumbs` → `out/<v>/stills/thumb_*.jpg` 1280×720: чистая сцена без HUD или своя композиция `window.THUMBS[draw]` в `video.js` + 2–4 крупных слова. Аватар/арт канала — `videos/brand` + `still.py --square N --hires K`.
10. Проверка готового MP4: ffprobe (1920×1080, 60 fps, yuv420p, AAC), кадры на стыках сцен из декодированного файла, громкость. Честно разделяй «проверено в кадрах» и «прослушано» — прослушать звук Claude не может, это проверяет человек.

## Языки (варианты ролика)
- `<ролик>:en` — тот же ролик с другой озвучкой: `script.en.json` (те же `id` строк и **то же число кусков `|`** в каждой строке), `voice/en/narration.mp3` + `words.json`, `timings.en.js` (`align.py basilisk:en`), `strings.en.js` (перевод надписей; в коде они обёрнуты в `tx('…')`). Все скрипты принимают `basilisk:en`, результат — в `out/basilisk-en/`. Числа выводи через `toLocaleString(LOCALE)` (en → «170,000»), локальные переменные не называй `tx`.
- Якоря слов в `video.js` пишутся по оригиналу; в варианте они переносятся на новую озвучку по относительной позиции внутри того же куска субтитров. Для важных синхронизаций задай точное соответствие в `script.en.json → anchors: {line: {"слово": "word" | "word#n"}}`.
- Английский голос по умолчанию: **Marcus K — Calm Documentary Narrator** `3H55HGnNE1XjYxigHSAS` (спокойный американский, научпоп без театральности).
- Для нового англоязычного ролика пиши `video.js` сразу по английскому `script.json` (язык оригинала — английский), надписи — по-английски.

## Рендер
- Chromium: Playwright сам, иначе `CHROMIUM_PATH` или `/opt/pw-browsers/chromium-*/chrome-linux/chrome`.
- Motion blur — `mbFn(t)` в ролике (сабкадры дорогие: держи n=2 по умолчанию, больше — только на быстрых переходах).
- Рендер по умолчанию 720p (`render.py --size 720`, решение заказчика): сцены рисуются на холсте 1920×1080 и уменьшаются в браузере — быстрее, а `finish.py` даёт один лёгкий файл ~20–40 МБ, который скачивается из чата. 1080p — только по запросу: `render.py --size 1080` → `<v>.mp4` (crf 20) + `<v>_720p.mp4`; для скачивания 1080p — ветка `renders` (файл до 100 МБ).
- `out/` не коммитится. Голос (`voice/*.mp3`, `words.json`) и `timings.js` — коммитятся.
