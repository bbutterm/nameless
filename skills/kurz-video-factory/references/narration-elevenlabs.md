# Озвучка: ElevenLabs

## Голос и модель
- **Голос: Fuad**, `voice_id = dWNEQ4rqRY6thcusuDyq` (библиотечный, русский, глубокий баритон, «для документалок и тёмных историй»). Заказчику понравился — по умолчанию для научпопа с мистикой.
- **Модель: `eleven_v4`** (понимает теги эмоций). Если недоступна — `eleven_v3`; без тегов — `eleven_multilingual_v2` (тогда теги убрать, паузы делать `<break time="0.8s" />`).
- 4 дубля одного текста, выбрать лучший. Стоимость ориентировочно ~1 кредит за символ на дубль (2 300 символов × 4 ≈ 9 300 кредитов ≈ $1.7 на «Василиске»). Перед генерацией оцени и скажи пользователю.

## Теги и пунктуация (eleven_v4)
- Теги в квадратных скобках перед фразой: `[curious]`, `[mischievously]`, `[calm]`, `[softly]`, `[whispers]`, `[pause]`, `[short pause]`. Тег действует до следующего — ставь только там, где меняется подача. В «Василиске»: `[curious]` в хуке, `[mischievously]` на «добро пожаловать», `[calm]` на «хорошие новости», `[softly] … [pause] [whispers] Наверное.` в финале.
- Многоточие — длинная пауза, тире — короткая, абзац (пустая строка между блоками) — пауза между смысловыми кусками.
- Числа на v4 можно писать цифрами («2010 года», «170 тысяч»).
- Английские названия (LessWrong) v4 читает нормально; если что-то читается криво — замени в `say` транскрипцией, в `text` оставь как есть.

## Как выбрать дубль (если не можешь слушать)
- Длительность: самый быстрый часто «тараторит», самый медленный даёт больше воздуха визуалу (в «Василиске» выбран самый длинный, 2:34 из 2:20–2:34).
- `ffmpeg -af silencedetect=noise=-40dB:d=0.5` — паузы должны быть на границах абзацев, без странных провалов посреди фразы.
- `ebur128` — громкость дублей близкая, без пиков.
- Честно скажи пользователю, что выбрал по метрикам, и дай ссылки/файлы всех дублей, чтобы он мог переслушать.

## Тайминги слов — обязательно
Анимация синхронизируется по словам, поэтому нужен `voice/words.json` вида `{"words":[{"text":"Есть","start":0.16,"end":0.32}, …]}`.

**Вариант A — ElevenLabs MCP-коннектор** (как делал Claude):
1. `creative_create_flow` → `creative_generate_speech` (`estimate_only:true` → потом по-настоящему) → опрос `creative_get_flow_run_status` до `all_completed`.
2. Скачать дубли по `content_url` (живут ~2 ч).
3. `creative_add_flow_asset_node` с `generation_id` выбранного → `creative_transcribe_audio` (`eleven_scribe_v1`, `connect_from` = этот узел) → скачать `words_download_url` в `voice/words.json`.

**Вариант B — REST API** (нужен ключ `ELEVENLABS_API_KEY`): `engine/tts_elevenlabs.py`
```bash
python3 engine/tts_elevenlabs.py <slug> --takes 4     # endpoint /with-timestamps: аудио + выравнивание символов → слова
python3 engine/tts_elevenlabs.py <slug> --pick 3      # выбранный дубль → voice/narration.mp3 + words.json
python3 engine/tts_elevenlabs.py <slug> --transcribe some.mp3   # или тайминги для готовой записи через Scribe
```
(Скрипт написан по документации API и не прогонялся на живом ключе — при ошибке читай ответ сервера и поправь поля запроса.)

После этого: `python3 engine/align.py <slug>` → `timings.js`. Скрипт сам выкидывает теги и сопоставляет слова `say` со словами транскрипции; если пишет «cannot align word» — текст `say` расходится с тем, что прочитано.

## Баланс в миксе
Речь на 10–13 дБ громче музыки, SFX ещё тише на фоне речи (короткие пики допустимы). В «Василиске»: `MASTER = {'duck': 0.6, 'mgain': 0.45, 'sgain': 0.6}`. Проверяй замером RMS по кускам (код — в `qa-and-pitfalls.md`). Итоговая громкость −14 LUFS делает `finish.py`.
