# Проверка и грабли

## Перед полным рендером
- Контактные листы по всему ролику с шагом ~1.5–2 с и отдельно на стыках сцен (`preview.py`). Смотри глазами каждый лист:
  - нет пустых кадров дольше 0.4 с (кроме задуманной паузы);
  - текст и ярлыки внутри кадра, не обрезаны, не наезжают на героев;
  - герой и главный объект читаются, не перекрыты змеем/толпой/интерфейсом;
  - композиция не «прилипла» к верху или низу (если пусто снизу — сдвинь `y` камеры);
  - эмоция и взгляд героя соответствуют фразе.
- `node --check`, отсутствие ошибок в консоли (preview печатает `errors []`; одна ошибка «file not found» без `timings.js` — нормальна).

## После рендера (готовый MP4)
```bash
ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate,pix_fmt,nb_frames -of compact out/<v>/<v>.mp4
ffmpeg -ss <t> -i out/<v>/<v>.mp4 -frames:v 1 check_<t>.jpg       # кадры вокруг каждой границы Bd
ffmpeg -i out/<v>/<v>.mp4 -af ebur128=peak=true -f null -          # ≈ −14 LUFS
```
Баланс голос/музыка (до сведения):
```python
# в mix-окружении: vo, mus, sf — моно-сигналы после усилений; сравни RMS в дБ по кускам речи
rms = lambda x, a, b: 20*np.log10(np.sqrt(np.mean(x[T(a):T(b)]**2)) + 1e-9)
```
Цель: голос на 10–13 дБ громче музыки. Звук ты не слышишь — так и скажи; на слух проверяет человек.

## Грабли, на которые уже наступили
1. **Префиксный поиск слова**: `at('hook','и')` нашёл «идея», `at('copy','кто')` — «кто давно умер» вместо «кто сказал», `at('threat','Не')` — «не помог» вместо «Не из злобы», `at('blackmail','Если')` — «только если». Проверяй каждое неоднозначное слово.
2. **`const L = id => lw(...)`** без второго параметра → `L('каждый', 1)` возвращает первое слово → ключи камеры не по порядку → камера улетает за кадр. Всегда `(id, n = 0)`.
3. Ярлык в экранных координатах по ошибке поставлен на `y = -10` → вне кадра. Экранные элементы рисуй после `ctx.restore()` камеры и проверяй границы.
4. Длительность звукового события может стать отрицательной из-за неверного слова → `scipy` падает на пустом массиве. Если `mix.py` падает — сначала проверь события с `d <= 0`.
5. **Музыка была слишком громкой** (всего на 4–6 дБ тише голоса) — опустили `mgain` до 0.45.
6. **Зерно раздувает файл**: зерно меняется в каждом кадре → мастер с crf 16 весит ~40 Мбит/с (851 МБ на 2:48). Финал перекодируется с crf 20 slow (~9.5 Мбит/с) и ещё делается 720p ~20 МБ. Кодек сглаживает шум, формы не страдают.
7. **Файл 200+ МБ не скачивается из чата** — отдавай 720p (~20 МБ) и 1080p ≤100 МБ (`-crf 22 -maxrate 3.6M -bufsize 7M`).
8. **Фигура со спины за компьютером** — забракована. Вид сбоку/¾, лицо в кадре.
9. Пустые полсекунды в начале сцен, где первое событие привязано к слову чуть позже, — добавляй объект с первого кадра сцены (появление заранее, проявление).
10. Большие зумы радиальных градиентов (нырок в зрачок ×14) замедляют рендер — держи такие куски короткими.
11. Субкадры motion blur ×6 на всём ролике удваивают время рендера — только у быстрых переходов.
12. Перерендер — 20 минут. Поэтому сначала два прохода по контактным листам, потом полный рендер.
