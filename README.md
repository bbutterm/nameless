# Безымянный

Соло нарративный рогалик-RPG для вертикального мобильного браузера (PWA).

Бессмертный без памяти приходит в себя в чулане Великого Ломбарда города Заклад —
города, где память материальна и служит валютой. Каждая смерть навсегда
возвращает ему одно воспоминание из собственного заложенного прошлого. Смерть
здесь не проигрыш, а единственный работающий способ вернуть себе себя.

Выборы игрока смещают четыре **скрытые** оси личности (числа не показываются
никогда). Оси решают, какие варианты ответа игрок вообще увидит, кто согласится
идти с ним в бой и **какая из пяти прошлых жизней вспомнится при смерти**.
Прохождения расходятся радикально.

## Запуск

```bash
pnpm install
pnpm dev          # клиент на http://localhost:5173 (открывать в мобильном режиме, портрет)
```

## Проверки

```bash
pnpm typecheck    # TypeScript strict во всех пакетах
pnpm validate     # схемы и ссылочная целостность контента
pnpm test         # юнит-тесты движка
pnpm sim          # винрейты юнитов + фаззер диалогов
pnpm ci           # всё вместе
```

## Структура

| Пакет | Что внутри |
|---|---|
| `packages/engine` | Чистая логика: бой, оси/флаги, фильтрация диалогов, seeded RNG, сейвы. Ноль зависимостей от UI. |
| `packages/content` | Весь контент данными (JSON) + zod-схемы + валидатор целостности. Добавление контента = добавление файла. |
| `packages/client` | React + Vite, PWA, вертикальный интерфейс, тёмная тема, ru/en. |
| `packages/sim` | Симулятор боёв бот-vs-бот и фаззер диалогов. |

## Свой арт

Положи изображение в `packages/content/assets/cards/` с именем файла = id юнита
(например `gar.webp`), соотношение сторон 3:4 — оно автоматически заменит
процедурную заглушку. Перекомпилировать ничего не нужно.

## Документы

Единый источник правды — `/docs`. Читать перед любой правкой контента:

- `CANON.md` — мир, тон, центральная тайна, прошлые жизни, запреты. **Закон.**
- `MECHANICS.md` — формулы боя, осей, прогрессии.
- `STORY_GLOBAL.md` — арки глав, ветвление жизней, схема переменных.
- `CHARACTERS.md` — досье персонажей: голос, секреты, отношение к осям.
- `STYLE.md` / `ASSETS_LIST.md` — палитра, шрифты, источники временной графики.
- `PROGRESS.md` — журнал решений. `MORNING_REPORT.md` — сводка.
